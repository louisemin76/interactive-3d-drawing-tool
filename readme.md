# Interactive Web-based 3D Drawing Tool

A web-based interactive 3D drawing tool built with Three.js.
Users can draw strokes on a plane and automatically generate 3D objects along the path.

## Features

- Draw with the mouse
- Automatically place 3D models along the drawn path
- Orbit camera controls
- GLTF model loading
- Web-based interaction

## Setup
Download [Node.js]

``` bash
npm install

npm run dev

npm run build
```
